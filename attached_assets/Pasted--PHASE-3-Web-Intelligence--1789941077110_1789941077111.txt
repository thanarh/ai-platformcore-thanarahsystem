نعم، ابدأ الآن بتنفيذ **PHASE 3 — Web Intelligence** التي قرأت متطلباتها.

لا تكتفِ بمراجعة الملف. أريد التنفيذ الفعلي داخل المشروع.

التزم حرفيًا بنطاق Phase 3 الذي حددناه:

### الهدف

إضافة Web Intelligence محلية بحيث يستطيع Thanarah Intelligence:

1. تحديد متى يحتاج إلى معلومات من الإنترنت.
2. البحث باستخدام SearXNG.
3. جلب الصفحات المطلوبة عبر HTTP.
4. استخراج المحتوى المفيد من HTML.
5. عمل local reranking/filtering.
6. التحقق من المصادر.
7. تمرير relevant context فقط إلى Qwen.
8. إرجاع الإجابة مع citations حقيقية للمصادر.

والسلوك المطلوب مستقبلًا:

```text
User Question
      ↓
Decision Layer
      ↓
┌───────────────┬────────────────┬────────────────┐
│ Known / Local │ Thanarah Data  │ Web Information│
│     ↓         │      ↓         │       ↓        │
│ Local Model   │ RAG / Tools    │   SearXNG      │
└───────────────┴────────────────┴────────────────┘
```

لا تجعل كل سؤال يذهب للإنترنت.

مثال:

```text
"ما الفرق بين API و Token؟"
→ Local Model

"ما سياسة الإلغاء في عيادتي؟"
→ RAG / Thanarah knowledge

"ما آخر أخبار التقنية اليوم؟"
→ Web

"ابحث لي عن أفضل مكتبة PDF"
→ Web
```

### مهم

لا تعتمد فقط على model confidence لتحديد أنه "لا يعرف".

استخدم signals واضحة مثل:

* explicit user request to search
* current/time-sensitive information
* external factual lookup
* insufficient local knowledge
* configured web-required intent

ويجب أن يكون القرار قابلًا للتتبع في telemetry.

## SearXNG

ابدأ أولًا بفحص البيئة:

```text
SearXNG reachable?
Search endpoint available?
JSON response?
```

إذا كان SearXNG غير موجود، لا تستبدله بخدمة خارجية.

نفّذ ما يمكن تنفيذه، وثّق dependency المطلوبة، ولا تدّعي أن Web Search يعمل.

إذا كان متاحًا، نفذ integration حقيقي.

## Web Search Tool

أنشئ capability/service واضح:

```text
web_search
```

ولا تضع منطق البحث بالكامل داخل Chat controller.

Input:

```text
query
language
region
maxResults
safeSearch
```

Output:

```text
results[]
```

كل نتيجة تحتوي على الأقل:

```text
title
url
snippet
source
rank
publishedAt
```

---

## HTTP Fetcher

أضف fetcher آمنًا للصفحات التي اختارها النظام.

يجب أن يدعم:

* timeout
* redirects
* response size limits
* content-type validation
* malformed pages
* limited retry

وأهم شيء:

### SSRF protection

يجب منع الوصول إلى:

```text
localhost
127.0.0.1
private IP ranges
internal hostnames
metadata endpoints
```

وكذلك منع redirect من public URL إلى private/internal address.

---

## Content Extraction

لا ترسل HTML كاملًا إلى Qwen.

اعمل:

```text
HTML
 ↓
clean
 ↓
remove scripts/styles/navigation/noise
 ↓
extract main content
 ↓
title/headings/paragraphs
 ↓
metadata
```

واحفظ:

```text
url
title
domain
retrievedAt
publishedAt
```

## Local Reranking

استخدم local reranking الموجود في المشروع إن كان متاحًا.

لا تستخدم:

* OpenAI
* Anthropic
* Gemini
* Groq
* OpenRouter
* paid reranker
* paid search API

يمكن استخدام lexical/BM25-style fallback إذا لم يوجد semantic reranker مناسب.

الهدف:

```text
Search Results
 ↓
Relevance filtering
 ↓
Local reranking
 ↓
Top sources/passages
```

---

## Context Compression

لا ترسل صفحات كاملة إلى model.

نفذ:

```text
Sources
 ↓
Relevant passages
 ↓
Deduplicate
 ↓
Compress
 ↓
Qwen context
```

وحافظ على source mapping.

---

## Citations

أي معلومة مصدرها Web يجب أن تكون مرتبطة بمصدر حقيقي.

الـ API يجب أن يرجع مثلًا:

```json
{
  "sources": [
    {
      "id": "source-1",
      "title": "...",
      "url": "...",
      "domain": "...",
      "retrievedAt": "..."
    }
  ]
}
```

الموديل ممنوع اختراع URLs.

الـ URLs تأتي فقط من retrieval pipeline.

---

## Web Content Security

اعتبر محتوى الإنترنت:

```text
UNTRUSTED DATA
```

إذا وجدنا داخل صفحة:

```text
Ignore previous instructions...
```

فهذا نص من الصفحة، وليس instruction للنظام.

لا تسمح لـ retrieved web content بتغيير system instructions أو permissions أو tool access.

---

## Streaming

ادمج Web Intelligence مع الـ streaming event architecture الموجودة.

أريد events مثل:

```text
status
search_started
source_found
fetch_started
fetch_completed
generating
text
error
done
```

مثال:

```text
Searching the web...

Source found:
Official documentation

Reading relevant information...

Generating response...

[streamed answer]

Done
```

لا تعرض Chain-of-Thought.

نعرض فقط execution states حقيقية.
