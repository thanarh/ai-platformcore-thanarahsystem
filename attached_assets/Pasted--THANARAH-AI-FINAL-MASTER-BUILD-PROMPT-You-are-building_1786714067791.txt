# THANARAH AI — FINAL MASTER BUILD PROMPT

You are building a real production-grade AI platform named:

# THANARAH AI | ثناره AI

This system is part of the Thanarah ecosystem.

This is NOT:

* a demo chatbot
* a simple OpenAI wrapper
* a Groq wrapper
* a Gemini wrapper
* an Anthropic wrapper
* a single-provider application

The goal is to build an independent AI infrastructure owned by Thanarah that can serve clinics, companies, employees, developers, and future Thanarah products.

# 1. CORE PRINCIPLE

The most important architectural rule is:

> Thanarah must own the AI platform, routing, data, memory, knowledge, APIs, tools, workflows and local/self-hosted inference capability.

External AI companies must NEVER become a required dependency.

The platform must work without:

* OpenAI API
* Anthropic API
* Gemini API
* Groq API
* DeepSeek API
* any other commercial AI provider

External providers may exist only as OPTIONAL adapters.

They must be disabled by default.
