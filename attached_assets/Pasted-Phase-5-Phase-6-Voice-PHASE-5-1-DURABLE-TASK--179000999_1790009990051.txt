Phase 5 تم اعتمادها.

لكن قبل Phase 6 Voice، لدينا متابعة ضرورية واحدة:

# PHASE 5.1 — DURABLE TASK & ARTIFACT PERSISTENCE

لا تعيد بناء Task Orchestrator.

لا تغير Skill architecture.

لا تبدأ Voice.

الهدف فقط إزالة الـprocess-local persistence boundary.

---

## 1. المشكلة الحالية

حاليًا:

```text
Task metadata
Artifact metadata
```

process-local.

وهذا يعني أن restart للـAI Engine قد يؤدي إلى فقدان:

* task state
* task result metadata
* artifact metadata
* artifact ownership mapping

هذا غير مقبول للإنتاج.

---

# 2. Persistence

استخدم قاعدة البيانات الموجودة بالفعل في المشروع.

لا تضف قاعدة بيانات جديدة.

لا تستخدم paid service.

احفظ:

```text
Task
TaskDependency
Artifact
```

مع:

```text
tenantId
userId
conversationId
requestId
```

---

# 3. Task Persistence

حالة Task يجب أن تبقى بعد restart:

```text
PENDING
READY
RUNNING
COMPLETED
FAILED
CANCELLED
BLOCKED
```

وعند restart:

```text
database
 ↓
recover tasks
 ↓
restore state
```

لا تعيد تشغيل Task مكتملة.

ولا تعيد تنفيذ Task مرتين بسبب restart.

---

# 4. Artifact Persistence

احفظ metadata بشكل durable:

```text
id
tenantId
userId
conversationId
taskId
type
name
mimeType
size
storagePath
createdAt
expiresAt
```

مع ownership checks.

---

# 5. Artifact Files

لا تستخدم process memory كـ source of truth للملف.

استخدم filesystem/storage abstraction واضحة.

مثال:

```text
ArtifactStore
├── create
├── save
├── getMetadata
├── getContent
├── delete
└── authorize
```

لا تربط الـcontroller مباشرة بالـfilesystem.

# 7. Dependency Verification

تحقق من الـruntime الفعلي، وليس requirements.txt فقط.

يجب إثبات أن environment الذي يعمل عليه الـworkflow يستطيع import:

```text
reportlab
openpyxl
pandas
```

واختبر فعليًا:

```text
PDF creation
XLSX creation
CSV creation
```

من نفس runtime المستخدم في التطبيق.

إذا كانت المكتبات غير متاحة، أصلح environment/dependency installation.

لا تعتمد على fallback لإنشاء production artifacts إذا كانت المكتبات المطلوبة جزءًا من التصميم.

ولا تقل إن dependency موجودة لمجرد وجودها في requirements.txt.

---

# 8. Artifact Integrity

بعد إنشاء كل artifact:

### PDF

تحقق من:

```text
file exists
mimeType correct
size correct
valid PDF signature
```

### XLSX

تحقق من:

```text
file exists
mimeType correct
valid XLSX/ZIP structure
```

### CSV

تحقق من:

```text
file exists
correct encoding
valid rows/columns
```

---

# 9. Security

أعد اختبار:

```text
User A → own artifact ✓
User B → User A artifact ✗

Tenant A → Tenant B artifact ✗

forged artifactId ✗
forged tenantId ✗
forged userId ✗
```

ولا تعتمد على ID secrecy.

---

# 10. Cleanup

ضع سياسة واضحة للـartifact lifecycle:

```text
expiresAt
```

ولا تحذف artifact ما زال referenced إذا كانت السياسة الحالية تمنع ذلك.

نفذ cleanup آمن للـexpired artifacts.

---

# 11. Concurrency

اختبر:

```text
Task A → Artifact
Task B → Artifact
Task C → Artifact
```

بالتوازي، وتأكد أن:

* IDs unique
* files don't overwrite each other
* metadata doesn't mix
* tenant ownership remains correct
