## أريد أيضًا تفكيك TTFT

قسّم Time To First Token إلى:

request overhead
+
context/retrieval
+
prompt construction
+
Ollama/model processing
+
first token

إذا كان هذا غير ممكن بدقة بسبب architecture الحالية، لا تخترع أرقامًا؛ اذكر الجزء الذي لا يمكن قياسه.

## CPU experiment

لدينا 12 CPU و24GB RAM.

اعمل benchmark صغيرًا وآمنًا على إعدادات Ollama الحالية، ثم جرّب إعدادات threads مناسبة فقط.

لا ترفع threads عشوائيًا.

قارن مثلًا إعداد current configuration مع 2 أو 3 configurations إضافية مناسبة للـ12 CPU.

لكل configuration سجل:

* TTFT P50
* TTFT P95
* Total P50
* Total P95
* tokens/sec
* CPU
* RAM

لا تختار configuration بناءً على التخمين؛ اخترها بناءً على benchmark.

## Context experiment

اختبر تأثير طول الـcontext على latency باستخدام حالات قصيرة ومتوسطة وطويلة.

لا تغير جودة المحادثة في production بناءً على benchmark فقط.
