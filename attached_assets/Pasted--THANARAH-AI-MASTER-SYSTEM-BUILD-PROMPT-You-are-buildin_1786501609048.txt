# 2. IMPORTANT ARCHITECTURE PRINCIPLE

Never tightly couple Thanarah to one AI model.

Build:

**Thanarah Intelligence Router — TIR**

Every AI request must go through this router.

Architecture:

```text
User
    ↓
Thanarah Chat
    ↓
API Gateway
    ↓
Authentication
    ↓
Tenant Resolver
    ↓
Context Builder
    ↓
Thanarah Intelligence Router
    ↓
┌────────────────────────────────────────────┐
│ Thanarah Local AI                         │
│ Client/Edge AI                            │
│ BYOK Provider                             │
│ Approved External Provider Adapter        │
│ Tool / Workflow                           │
│ RAG                                       │
│ Cache                                     │
└────────────────────────────────────────────┘
    ↓
Response Processor
    ↓
Memory
    ↓
User
```

The router must be modular.

Adding or removing an AI backend must NOT require rewriting the application.
