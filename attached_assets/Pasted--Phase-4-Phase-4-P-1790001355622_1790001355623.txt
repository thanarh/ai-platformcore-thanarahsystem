توقف.

التقرير الذي أرسلته هو **Phase 4** مرة أخرى، وPhase 4 تم تنفيذها واعتمادها بالفعل.

لا تعيد Phase 4.
لا تعيد Gateway.
لا تعيد ToolRegistry.

# ابدأ الآن PHASE 5 فعليًا

## PHASE 5 — TASK ORCHESTRATOR + SKILLS + ARTIFACTS

الهدف الآن هو الانتقال من:

```text
Chatbot
+
Gateway
+
Tool Registry
```

إلى:

```text
User Request
      ↓
Capability / Skill
      ↓
Task Orchestrator
      ↓
Task Graph
      ↓
Execution
      ↓
Structured Result
      ↓
Artifact
      ↓
Final Response
```

---

# 1. Task Orchestrator

أنشئ service حقيقي باسم واضح مثل:

```text
TaskOrchestrator
```

مسؤوليته:

* إنشاء tasks
* تحديد dependencies
* تحديد READY tasks
* تشغيل tasks
* تشغيل المستقل منها بالتوازي
* انتظار dependencies
* التعامل مع failure
* cancellation
* timeout
* جمع النتائج
* إنشاء artifacts

لا تستخدم Agent loop لا نهائي.

---

# 3. Task Graph

يجب دعم:

```text
A → B → C
```

وأيضًا:

```text
       → B ─┐
A ─────┤    ├→ D
       → C ─┘
```

B وC يمكن تشغيلهما بالتوازي إذا لم توجد dependency بينهما.

ضع:

```text
concurrency limit
timeout
cancellation
failure propagation
```

ولا تستخدم unlimited parallel execution.
